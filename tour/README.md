# جولة إيواء (landing v2)

- `site/index.html` = مسار مدير المخيم، `site/org/index.html` = مسار المؤسسة (يُبنى بـ `python3 tour/build.py` من `tour/org_body.html` + الأجزاء المشتركة في الصفحة الأولى، ويحقن نص الجولة من `tour/lines.tsv`).
- `site/a/e.css` و `site/a/e.js`: التصميم، والتجارب التفاعلية، ومحرك الجولة (فصول، انتظار فعل الزائر ثم ردّ صوتي، وإن لم يفعل شيئًا خلال ~14 ثانية تعرض الجولة الفعل بنفسها).
- الصوت: `site/audio/camp/*.mp3` (صوت الفيلم 1، لهجة فلسطينية خفيفة) و `site/audio/org/*.mp3` (صوت الفيلم 2، فصحى مشكّلة). وُلّد كل مسار بأخذة واحدة في ElevenLabs (eleven_v4، مشروع «إيواء — جولة الموقع»)، ثم قُصّ بمحاذاة faster-whisper، وكل مقطع فُحص نطقه. `bed-*.mp3` موسيقى خفيفة من موسيقى الفيلمين.
- المؤثرات (ختم، ورقة، نغمة وصول) مولّدة داخل المتصفح بـ WebAudio، بلا ملفات.
- لا صوت قبل ضغطة الزائر، والنص المكتوب يظهر دائمًا في شريط الجولة.
- لتعديل جملة: عدّل `tour/lines.tsv`، وولّد المقطع نفسه فقط، ثم شغّل `build.py`.
